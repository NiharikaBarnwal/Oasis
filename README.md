# Oasis Infobyte - Web Development and Designing Internship

Welcome to my GitHub repository for the **Oasis Infobyte Web Development and Designing Internship**. This repository contains the projects I completed as part of the internship, which lasted for a duration of **one month**.

## About the Internship
The **Oasis Infobyte** internship provided an excellent opportunity to enhance my web development and designing skills. Throughout the program, I worked on various projects that helped me understand front-end development, back-end integration, and UI/UX design.

## Projects Completed
The repository includes the following projects:

1. **Calculator**
   - A functional calculator built using **HTML, CSS, and JavaScript**.
   - Supports basic arithmetic operations.

2. **Form**
   - A responsive form built using **HTML, CSS, JavaScript, PHP, and SQL**.
   - Includes form validation and user-friendly design.

3. **To-Do List**
   - A task management application developed with **HTML, CSS, and JavaScript**.
   - Allows users to add, delete, and mark tasks as completed.

4. **Tribute Page**
   - A tribute page created using **HTML and CSS**.
   - Showcases a well-structured and visually appealing design.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Styling:** CSS, Bootstrap

## How to Use
1. Clone the repository:
   ```sh
   git clone https://github.com/NiharikaBarnwal/oasis-infobyte.git
   ```
2. Navigate to the project folder:
   ```sh
   cd Oasis
   ```
3. Open the files in a browser or run on a local server.
